# Imágenes de líneas de e-liquid

La web intenta primero imágenes locales en esta carpeta. Si existen, reemplazan automáticamente las referencias remotas.

Archivos recomendados:

- `tradicional.webp`
- `premium.webp`
- `clon.webp`
- `salts.webp`
- `galaxy.webp`

También acepta PNG, JPG y JPEG como fallback.

El diseño las usa como **packshot de fondo** dentro de cada tarjeta de línea, con un degradado oscuro para mantener legibles los selectores.

Mientras no exista el archivo local, la aplicación usa una imagen representativa pública de Anubis para la línea cuando está disponible y un visual general de Anubis como fallback.
